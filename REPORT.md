## 1. Теоретическое описание

### 1.1 Описание предметной области
Проект «NEO STUDY» представляет собой интерактивную веб-платформу, предназначенную для подготовки учащихся к профильному уровню ЕГЭ по математике. В современных условиях дистанционного образования критически важным становится наличие инструментов, которые не просто проверяют ответ, но и предоставляют методическую поддержку в реальном времени.

### 1.2 Характеристика учебных материалов
Учебная база разделена на фундаментальные блоки, соответствующие спецификации контрольно-измерительных материалов (КИМ):
- Планиметрия и стереометрия;
- Теория вероятностей (базовая и сложная);
- Алгебраические уравнения и вычисления;
- Производная и графики функций.

### 1.3 Описание технологий веб-разработки
Система построена на современном стеке технологий:
- **Frontend:** Библиотека React 19, обеспечивающая компонентную архитектуру и высокую скорость работы интерфейса.
- **Backend:** Микрофреймворк Flask (Python), обрабатывающий API-запросы и взаимодействие с базой данных.
- **Связь:** Библиотека Axios для асинхронного обмена данными между клиентом и сервером.

### 1.4 Характеристика методов рендеринга формул
Для корректного отображения сложных математических выражений (логарифмы, интегралы, дроби) используется библиотека **KaTeX**. Она позволяет рендерить формулы в формате LaTeX непосредственно в браузере с высокой производительностью и типографическим качеством.

### 1.5 Описание технологий анимации и интерфейса
Интерфейс платформы выполнен в стиле «Bento Grid» с использованием библиотеки **Framer Motion**. Это обеспечивает плавные переходы между страницами, анимацию появления элементов и интерактивный отклик на действия пользователя, что снижает когнитивную нагрузку при обучении.

### 1.6 Принципы работы интеллектуального ассистента (LLM)
В систему интегрирована большая языковая модель (через Yandex Cloud API). ИИ выступает в роли персонального репетитора, который анализирует ошибки ученика и дает подсказки, не называя правильного ответа, что стимулирует самостоятельное решение задачи.

### 1.7 Описание метрик прогресса
Успеваемость пользователя оценивается через систему игровых рангов:
- **Новичок:** 0 решенных задач.
- **Ученик:** до 5 задач.
- **Профи/Магистр/Легенда:** при достижении соответствующих порогов сложности и количества.

## 2. Разработка системы обучения и анализа

### 2.1 Проектирование архитектуры базы данных
Использована реляционная СУБД с ORM-системой SQLAlchemy. Структура включает таблицы пользователей (`User`), банк заданий (`Task`) и журнал решений (`SolvedTask`), что позволяет отслеживать индивидуальный прогресс каждого ученика.

### 2.2 Реализация системы аутентификации и ролей
Доступ к системе разграничен на основе ролей:
- **Student:** доступ к тренажеру и личной статистике.
- **Admin:** возможность управления базой задач и просмотра аналитики всех пользователей.
Безопасность обеспечивается токенами **JWT (JSON Web Token)**.

### 2.3 Разработка модуля двухуровневой навигации
Реализована логика «Категории -> Задания». Пользователь сначала выбирает интересующую его тему (например, «Стереометрия»), видит свой прогресс в ней, и только затем переходит к списку конкретных упражнений.

### 2.4 Алгоритм автоматизированной проверки ответов
Алгоритм включает нормализацию ввода: автоматическую замену запятых на точки, удаление лишних пробелов и приведение к единому регистру. Это минимизирует количество технических ошибок при вводе правильных решений.

### 2.5 Интеграция модуля ИИ-подсказок (Yandex GPT)
Разработан механизм формирования промптов, включающий условие задачи и неверный ответ пользователя. ИИ генерирует подсказку, содержащую:
1. Анализ возможной ошибки.
2. Необходимую математическую формулу.
3. Совет по первому шагу решения.

### 2.6 Адаптация системы для работы в локальной сети
Для обеспечения доступа с нескольких устройств в рамках одной сети реализовано динамическое определение IP-адреса сервера (`window.location.hostname`). Это позволяет запустить проект на одном ПК и предоставить доступ коллегам или ученикам по локальной ссылке.

### 2.7 Визуализация статистики и геймификация
Статистика визуализирована с помощью индикаторов прогресса в каждой категории и динамических бейджей рангов, которые меняют цвет и эффекты (свечение) в зависимости от уровня знаний пользователя.

### 2.8 Верификация и тестирование системы
Проведено функциональное тестирование всех модулей: от регистрации пользователей до корректности отображения LaTeX-формул в ИИ-подсказках. Подтверждена стабильная работа системы при одновременном доступе нескольких пользователей.

Интеграция современных веб-технологий и искусственного интеллекта позволила создать инструмент, который эффективно заменяет классические статические сборники задач, обеспечивая персонализированный подход к каждому учащемуся.
